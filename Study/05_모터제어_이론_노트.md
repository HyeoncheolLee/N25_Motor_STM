# 05. 모터 제어 이론 노트

> 스터디용 이론 정리. N25 코드와 연결되는 부분은 **[N25]**로 표시한다.

---

## 1. BLDC vs PMSM

| 구분 | BLDC (좁은 의미) | PMSM |
|------|------------------|------|
| 역기전력 파형 | 사다리꼴 | 정현파 |
| 구동 | 6-step (120° 통전), 홀센서 | FOC (정현 전류), 엔코더 |
| 토크 리플 | 큼 (전환 시) | 작음 |

실무에서는 둘 다 "BLDC"라고 부르는 경우가 많다. **[N25]**는 SVPWM + FOC를 쓰므로 PMSM 방식으로 제어한다.

## 2. PMSM 수학 모델 (dq 좌표계)

```
v_d = R·i_d + L_d·di_d/dt − ω_e·L_q·i_q
v_q = R·i_q + L_q·di_q/dt + ω_e·L_d·i_d + ω_e·ψ_m

T_e = 1.5·p·[ψ_m·i_q + (L_d − L_q)·i_d·i_q]     (진폭불변 변환)
    ≈ 1.5·p·ψ_m·i_q = K_t·i_q                  (표면부착형, L_d ≈ L_q)

J·dω_m/dt = T_e − T_L − B·ω_m − T_c·sgn(ω_m)
```
- `ω_e = p·ω_m` : 전기 각속도
- `ω_e·ψ_m` : 역기전력 (속도에 비례 → 최고속도에서 전압 여유 필요)
- `−ω_e·L_q·i_q`, `+ω_e·L_d·i_d` : **교차결합 항** → 고속에서 디커플링 FF로 제거
- `T_L` : 부하토크 (바닥 마찰, 경사, 가속 저항) → **DOB로 추정하는 대상**

---

## 3. 좌표 변환

### Clarke (abc → αβ), 진폭불변
```
i_α = i_a
i_β = (i_b − i_c)/√3            [N25: beta = 0.57735·(S − T)]
```
### Park (αβ → dq)
```
i_d =  cosθ·i_α + sinθ·i_β
i_q = −sinθ·i_α + cosθ·i_β
```
### 역Park (dq → αβ)
```
v_α = cosθ·v_d − sinθ·v_q
v_β = sinθ·v_d + cosθ·v_q
```

## 4. SVPWM

- 6개 유효벡터 + 2개 영벡터로 원하는 전압벡터를 합성
- 섹터 n에서: `T1 = √3·Ts·|V|/Vdc·sin(60° − θ')`, `T2 = √3·Ts·|V|/Vdc·sin θ'`, `T0 = Ts − T1 − T2`
- 선형 최대 위상전압 = **Vdc/√3** (사인 PWM의 Vdc/2보다 15.5% 큼)
- **[N25]** `SPACE_VECTOR_COMMUTATION_Double()` — Vbus 고정 48V 가정. 실제 Vbus로 나누는 보상이 필요하다.

## 5. 캐스케이드 제어와 튜닝

```
θ* →[P]→ ω* →[PI]→ i_q* →[PI]→ v_q* → SVPWM
       ↑ω_ff       ↑i_ff(J·α/Kt + 마찰 + DOB)
```

### 5.1 전류 루프 (RL 플랜트)
- 플랜트: `G(s) = 1/(L·s + R)`
- PI: `C(s) = Kp + Ki/s`
- **극-영점 상쇄 튜닝**: `Ki/Kp = R/L` → 폐루프 ≈ 1차, 대역폭 `ωc = Kp/L`
```
Kp = L·ωc,   Ki = R·ωc
이산화(Ts):  Ki_d = Ki·Ts
```
- ωc 상한: PWM/샘플링 지연 때문에 대략 `ωc ≤ 2π·f_s/20`
- **[N25] 현재 값 해석** (표기 단위 기준): Kp = 0.7 V/A, Ki = 0.01·20000 = 200 V/(A·s) → 영점 `Ki/Kp ≈ 286 rad/s`. R/L과 비교하면 극-영점 상쇄 여부를 판단할 수 있다 → **R, L 실측 필요**. SVPWM 스케일(문서 03 §3.2)까지 감안하면 실제 Kp는 Vbus/96 배가 될 수 있다.

### 5.2 속도 루프
- 플랜트(전류 루프를 이상적이라 가정): `ω/i_q = Kt/(J·s + B)`
- 대역폭: 전류 루프의 1/5 ~ 1/10
- **대칭 최적(Symmetric Optimum)** 또는 대역폭 기준 설계: `Kp_ω = J·ω_ω/Kt`, `Ki_ω = Kp_ω·ω_ω/4~/10`
- 적재 시 J 변화 → 대역폭이 J에 반비례로 감소 → **DOB 또는 게인 스케줄링**

### 5.3 위치 루프
- 보통 P만 사용 (속도 루프의 적분이 정상오차 제거)
- 대역폭: 속도 루프의 1/3 ~ 1/5
- **[N25]** 속도 루프 없이 PD → i_q. D항이 사실상 속도 피드백 역할을 하지만 필터가 없고 적분이 없다.

## 6. 포화와 Anti-windup ★ (이번 이슈의 핵심)

### 6.1 Windup 이란
제어 출력이 포화된 동안 적분기(또는 적분 구조를 가진 기준)가 계속 오차를 쌓는다. 포화가 풀리면 쌓인 값 때문에 **큰 오버슈트**와 **느린 회복**이 생긴다.

### 6.2 대표 기법
| 기법 | 식 | 특징 |
|------|----|------|
| Clamping (조건부 적분) | 출력 포화 & 오차 부호가 포화를 심화시키는 방향이면 적분 정지 | 간단, 견고 |
| Back-calculation | `ẋ_I = Ki·e + Kb·(u_sat − u)` , 보통 `Kb ≈ 1/Ti` | 부드러움. **계수 스케일이 맞아야 함** |
| 적분기 클램프 | `|x_I| ≤ 한계` | 보조 수단 |

### 6.3 "기준 신호 windup" (N25 특유)
N25는 속도 명령을 적분해 위치 기준을 만든다 → **기준 자체가 적분기**다. 포화 시 이 적분도 멈추거나 제한해야 한다:
```c
// 개념 예시 (500Hz 위치 루프)
if (iq_saturated && sign(e) == sign(v_cmd)) {
    /* 기준 적분 보류 */
} else {
    REF_MUL += v_cmd;
}
// 또는 추종오차 클램프
e = REF - pos;
if (e >  E_MAX) { REF = pos + E_MAX; REF_MUL = REF*MUL; }
if (e < -E_MAX) { REF = pos - E_MAX; REF_MUL = REF*MUL; }
```

## 7. 외란 관측기 (DOB)

### 7.1 원리
```
          T_L (외란)
            ↓−
 i_q →[Kt]→(+)→ [1/(J_n s)] → ω
                  
 추정:  T̂_L = Q(s)·[ Kt·i_q − J_n·s·ω ]
 보상:  i_q* = i_q,ctrl + T̂_L / Kt
```
- `Q(s) = g/(s+g)` (1차 LPF, g = 관측기 대역폭)
- 공칭 모델 J_n과 실제 J의 차이, 마찰, 부하가 모두 "외란"으로 묶여 추정·보상된다 → **플랜트가 공칭 모델처럼 행동**
- 실무 구현은 `s·ω` 미분을 피하는 형태로 한다:
```
T̂_L = Q(s)·Kt·i_q − (g·J_n)·ω + Q(s)·(g·J_n)·ω
```

### 7.2 AMR 슬립 감지에 활용
- 정상 주행: T̂_L ≈ 굴림 저항 + 가속 반력 (완만)
- **슬립 발생**: 바닥 견인력이 동마찰로 떨어짐 → **T̂_L 급감**, 바퀴 가속도 급증
- **스톨/충돌**: T̂_L 급증, 속도 ≈ 0
- 판정 결과로 토크 한계를 동적으로 조절 → 트랙션 제어

### 7.3 주의
- 속도 추정 노이즈 → g를 너무 크게 하면 i_q 노이즈 증가
- 포화 시 DOB 보상분도 포화된다 → anti-windup 대상에 포함

## 8. 슬라이딩 모드 제어 (SMC)

- 슬라이딩 면 `s = ė + λ·e`, 제어 `u = u_eq − K·sgn(s)`
- 장점: 정합 외란(matched)에 불변, 유한시간 수렴
- 단점: **채터링** (sgn 스위칭) → 전류 고주파 리플 → FET 스위칭 손실·코일 철손·소음 증가
- 완화: 경계층 `sat(s/Φ)`, Super-twisting (2차 SMC), SMC 관측기(제어기 대신 관측기로 사용)
- **포화를 해결하지 못한다.** 포화 시 SMC도 windup과 비슷한 문제를 겪는다.

---

## 9. H∞ 제어

- 목표: 외란 w → 평가출력 z의 전달함수 무한대 노름 `‖T_zw‖∞ < γ` 최소화
- 가중함수(W1: 성능, W2: 제어입력, W3: 강건성)로 주파수 성형 → 모델 불확실성(J 변화 등)에 대한 **강건 안정성 보장**
- 결과는 고차 **선형** 제어기 → 포화 처리는 별도로 해야 한다
- 실무적으로는 "잘 튜닝된 PI + DOB"가 H∞ 설계와 비슷한 루프 성형을 하는 경우가 많다
- 학습 가치는 큼: 감도함수 S, 상보감도 T의 trade-off 이해

## 10. 최적 제어 / MPC

| 기법 | 핵심 | 비고 |
|------|------|------|
| LQR | `J = ∫(xᵀQx + uᵀRu)dt` 최소화 상태 피드백 | 좌우 바퀴 결합 모델에 적합 |
| LQG | LQR + 칼만 필터 | 노이즈 많은 속도 추정에 유용 |
| MPC | 매 주기 유한 구간 최적화, **제약조건 직접 반영** | 전류·전압·슬립 한계를 제약으로 넣을 수 있음. 20kHz 전류루프보다 상위 궤적 레벨에 적합 |
| FCS-MPC | 인버터 8개 스위칭 상태 중 최적 선택 | 연구 분야. 가변 스위칭 주파수 |

## 11. 휠-바닥 마찰과 슬립

### 11.1 슬립률
```
λ = (r·ω_wheel − v_robot) / max(r·ω_wheel, v_robot)
```
### 11.2 μ-λ 곡선 (Pacejka 등)
```
 μ
 │     ╭──╮  ← μ_peak (λ ≈ 0.1~0.2)
 │   ╱     ╲___  ← 슬립 영역: λ↑ 할수록 μ↓  (불안정 영역)
 │  ╱
 │ ╱
 └────────────── λ
```
- 피크 왼쪽: 안정 (토크↑ → 견인력↑)
- **피크 오른쪽: 불안정** (토크↑ → 슬립↑ → 견인력↓ → 더 슬립) — 양의 피드백
- 위치 windup 구조는 오차가 커질수록 토크를 올리므로 **불안정 영역으로 계속 밀어 넣는다**

### 11.3 최대 유효 토크
```
T_max,wheel = μ·N·r          (N: 바퀴 수직하중, 적재 시 증가)
I_q,slip    = T_max,wheel / (Kt · 감속비 · 효율)
```
→ 이 값보다 큰 전류 한계는 슬립만 늘린다. **적재량·바닥별 전류 한계 설정의 근거**가 된다.

## 12. 보호 설계 이론

### 12.1 I²t 열 모델
```
코일 온도 상승 (1차 열 모델):  τ_th · dΔT/dt = R_th · I²·R_s − ΔT
FW 근사:  heat += (I² − I_cont²)·dt ;  heat = max(heat, 0)
          heat > H_max → 전류 한계를 I_cont로 디레이팅 / 정지
```
- I_cont: 연속 정격 전류, H_max = (I_peak² − I_cont²)·t_peak_allowed

### 12.2 보호 응답 시간 계층
| 현상 | 시간 스케일 | 담당 |
|------|-------------|------|
| 상간 단락, 동시도통 | 수 µs | 게이트드라이버 VDS OCP, 비교기 → PWM Fault |
| 과전류 (제어 실패) | 50 µs ~ 1 ms | FW 20kHz ISR |
| 과전압 (회생) | 100 µs ~ ms | FW + TVS/브레이크 초퍼 |
| 코일 과열 | 초 ~ 분 | I²t + NTC |
| 스톨/슬립 | 100 ms ~ 1 s | 상태 감시 로직 |
