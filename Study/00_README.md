## 핵심 요약 (3줄)

1. **현재 구조는 "위치(PD) → 전류(PI)" 2단 구조이며 속도 루프가 없다.** 상위(AMR)에서 내려오는 속도 명령을 적분해 위치 기준으로 추종하므로, 슬립/걸림 시 위치 오차가 계속 누적되고 출력이 전류 한계(약 28A)에 포화된 채 유지된다.
2. **보호 기능이 사실상 "0.8초 지속 평균 전류" 하나에 의존한다.** 게이트드라이버 nFAULT 미사용, PWM 하드웨어 Fault 비활성, 상전류 순시 과전류 검출 비활성, DC 버스 전압 측정 없음, 온도 에러 핸들러 미호출 상태다.
3. 따라서 고장의 1차 원인은 "PI가 선형이라서"라기보다 **포화(saturation) + 오차 누적(windup) + 느린/누락된 보호 + 회생 에너지 미관리**일 가능성이 높다. 고급 제어(DOB/SMC/H∞)는 구조·보호를 먼저 바로잡은 뒤에 얹는 것이 순서다.

## 주의: 사용자 전제와 실제 HW 차이

- 사용자 설명은 "STM 기반 MCU 보드"였지만, 실제 N25 보드와 펌웨어는 **Microchip PIC32MK1024MCF064** (MIPS, 120MHz, MCPWM, XC32/MPLAB) 기반이다. 일반 가이드의 STM32 용어(TIM1, HAL 등)는 PIC32MK의 MCPWM/ADC 트리거로 바꿔 읽으면 된다.
- 엔코더는 iC-MU150 (자기식 Nonius 절대 엔코더) 2개가 실장되어 있다 (U9 주 엔코더, U13 보조).

## 스터디 진행 제안

| 주차 | 주제 | 실습 |
|------|------|------|
| 1 | PMSM 모델, Clarke/Park, SVPWM | `FOC.c`의 `FOC_CurrentControl_Double()` 손으로 따라가기 |
| 2 | 전류 루프 튜닝 (R, L 측정 → Kp, Ki 산출) | 모터 R/L 측정, 전류 Step 응답 로깅 |
| 3 | 캐스케이드(위치-속도-전류) 설계 | 현재 PD→Iq 구조를 P-PI-PI로 바꾸는 설계안 작성 |
| 4 | 포화·Anti-windup·추종오차 제한 | 바퀴 고정(락) 시험으로 windup 현상 재현 |
| 5 | 보호 설계 (HW/FW 계층) | nFAULT, VDS OCP, I²t, Vbus 보호 설계 |
| 6 | DOB / 부하토크 관측기 | 슬립 감지 로직 시뮬레이션 |
| 7+ | SMC, H∞, MPC 비교 | MATLAB/Simulink 또는 Python 시뮬레이션 |
