# 02. N25 하드웨어 분석 (회로도 AMR25DRV-5.00 기준)

## 1. 블록 구성

```
 48V (XT30) ──┬── 벌크 캡 (전해 2개 + 세라믹 2.2µF×3, 10µF) ── 3상 인버터 (BSC040N10NS5 ×6)
              │                                                  │  (상별 2mΩ 션트 + INA240A1)
              ├── DRV8350RH (게이트드라이버, 내장 Buck)            ├── M-U / M-V / M-W
              ├── LM5008A 계열 Buck → 5V → LM1117 → 3.3V          │
              └── 솔레노이드(브레이크) 드라이버 ×2 (MCP1416 + FET)
 PIC32MK1024MCF064 ── SPI ── iC-MU150 ×2, EEPROM(M95128)
                    ── QEI ── MU150 ABZ 출력
                    ── CAN ── TCAN3414
```

## 2. 주요 부품

| 기능 | 부품 | 핵심 사양 / 의미 |
|------|------|------------------|
| MCU | PIC32MK1024MCF064 | 120MHz MIPS, MCPWM, 12bit 고속 ADC, QEI ×2, CAN-FD |
| 게이트드라이버 | **DRV8350RH** (TI) | 100V급 3상 스마트 게이트드라이버, H = 하드웨어 설정형(저항으로 IDRIVE/VDS 설정), R = 내장 Buck. VDS 기반 단락 보호, UVLO, nFAULT 출력 |
| 전력 FET | **BSC040N10NS5** ×6 | 100V, RDS(on) ≈ 4mΩ, SuperSO8 |
| 게이트 회로 | 10Ω 직렬 + (1Ω + 쇼트키 NSR0520) | 턴온은 느리게, 턴오프는 빠르게 하는 비대칭 게이트 구성 |
| 전류센싱 | **INA240A1** ×3 + 2mΩ (CSRL3) | 상 직렬(in-line), Gain 20, PWM 공통모드 제거 기능 → 3상 모두 측정 가능 |
| 엔코더 | **iC-MU150** ×2 (U9, U13) | 자기식 오프축 Nonius 절대 엔코더. SPI 절대각 + ABZ 인크리멘탈 출력 |
| CAN | TCAN3414 | 3.3V CAN 트랜시버 |
| EEPROM | M95128 (SPI), M24C01 ×2 (I2C, MU150용) | 파라미터, MU150 설정 |
| 온도 | RT1: TSM2A103 (10k NTC, 보드) / TEMP1 (외부 커넥터, 모터 NTC용 추정) | |
| 브레이크 | MCP1416 + SSM3K361R ×2 | 솔레노이드 브레이크 (`Handler_Solenoid`) |

## 3. MCU 핀 매핑 (펌웨어 대조)

| 신호 | MCU 핀 | FW 사용 | 비고 |
|------|--------|---------|------|
| PWM_H1/L1 | RB14 / RB15 (PWM1) | `PDC1` | |
| PWM_H2/L2 | RB12 / RB13 (PWM2) | `PDC2` | |
| PWM_H3/L3 | RB10 / RB11 (PWM3) | `PDC3` | |
| ENABLE (DRV) | RA11 (pin 12) | `MOTOR_HIP_ON/OFF` (LATA11) | 일치 |
| **nFAULT (DRV)** | **RA7 (pin 1)**, 10k 풀업 | **미사용** | `status.c`는 `RE13`을 Fault로 읽도록 되어 있음 → **핀 불일치** |
| LED_STATUS | RE13 (pin 28) | `LATE13` 토글 (LED) | `status.c`의 `MOTOR_FAULT`와 같은 핀 |
| R_CUR / S_CUR / T_CUR | AN0(RA0) / AN1(RA1) / AN2(RB0) | `ADCDATA0/1/2` | 3상 모두 샘플링하지만 FW는 R, S만 사용 |
| TEMP (보드 NTC) | AN3 (RB1) | `ADCDATA3` | 온도 계산은 함 |
| TEMP1 (모터 NTC 추정) | AN4 (RB2) | **미사용** | |
| ENC_A/B/I | RG6/RG7/RG8 (QEI1) | `POS1CNT` | |
| ENC2_A/B | RE15/RE14 (QEI2) | `POS2CNT` | 보조 엔코더 |
| SPI | SCK/MOSI/MISO, CS | MU150, EEPROM | |
| **Vbus 측정** | — | — | **회로 없음** |

> PIC32MK의 PWM Fault 입력 가능 핀은 FLT3(RC2), FLT4(RC11), FLT5~8(RE12~RE15), FLT15(RB4) 등이다. nFAULT가 연결된 **RA7은 FLT 기능 핀이 아니다.** 그래서 게이트드라이버 Fault를 MCPWM 하드웨어 차단에 바로 쓸 수 없다. FW 인터럽트로 감시하거나, 다음 리비전에서 핀을 바꿔야 한다.

## 4. DRV8350RH 설정 핀 [확인 필요]

| 핀 | 연결 | 의미 |
|----|------|------|
| MODE (29) | R23 0Ω | PWM 모드 선택 (6x PWM 추정 — FW가 상보 6채널을 출력하므로) |
| IDRIVE (30) | R42 75kΩ | 게이트 소스/싱크 전류 설정 |
| VDS (31) | R46 75kΩ | **VDS 과전류 검출 임계 전압** |
| nFAULT (28) | R13 10k 풀업 → RA7 | Fault 시 Low |
| ENABLE (33) | RA11 | Low → 게이트 OFF (sleep) |

**해야 할 일**: 저항이 GND/DVDD 중 어디에 연결되는지 실물 또는 Altium 원본으로 확인하고, DRV8350 데이터시트의 저항값-레벨 표에 대입해 다음을 계산한다.
- **VDS OCP 임계 [V] / RDS(on) [4mΩ, 고온 시 약 6~7mΩ] = 단락 차단 전류**. 이 값이 너무 높으면(예: 1V → 150A 이상) 실질적인 보호가 되지 않는다.
- IDRIVE와 10Ω 게이트 저항을 함께 고려한 dV/dt → 링잉, SHx 음전압 언더슛 크기
- H 버전의 OCP 동작 모드(래치 셧다운 / 자동 재시도)와 tRETRY

## 5. 전류 센싱 계산

```
V_out = I × 0.002Ω × 20 = 0.04 V/A
ADC  = 3.3V / 4096 = 0.806 mV/LSB
→ 0.806 / 40 = 20.14 mA/LSB  (FW CURRENT_CONSTANT = 20.1416 ✔)
범위: 1.65V / 0.04 = ±41.25 A (상전류 피크)
```
- FW Iq 한계 ≈ 28A (진폭불변 변환이므로 상전류 피크 28A)는 측정 범위 안에 있다. 하지만 PI 오버슈트와 단락 시에는 **센서가 41A에서 포화**되어 실제 전류를 볼 수 없다. 이 영역은 HW 보호가 맡아야 한다.
- 션트 손실: 28A²/2 × 2mΩ ≈ 0.8W (상당). 장시간 피크 시 션트·PCB 온도 상승을 고려해야 한다.

## 6. 전력부 관찰 사항 (고장 연관)

| 관찰 | 위험 | 권장 확인/조치 |
|------|------|----------------|
| **Vbus 측정 회로 없음** | 회생 과전압 감지 불가. SVPWM이 48V 고정 가정 → 배터리 전압 변동 시 루프 이득 변동 | 다음 리비전에 분압 + ADC 추가 (필수) |
| **버스 TVS 미확인** (ESD용 PGB만 보임) | BMS 차단·커넥터 순간 단선 시 회생 에너지가 2.2µF×3 + 전해 캡에 몰려 **100V 초과 → FET/게이트드라이버 파괴** | 58~64V급 TVS 또는 브레이크 초퍼 검토, 커넥터 단선 시험 |
| 게이트 10Ω + 1Ω/쇼트키 | 턴오프가 빠름 → 큰 di/dt → 배선 인덕턴스로 VDS 서지, SHx 음전압 | 스위칭 노드 실측 (DRV8350 SHx 절대최대 정격과 비교) |
| nFAULT 미사용 | DRV가 OCP로 차단해도 FW는 모름 → 재시도/계속 명령 → **반복 스트레스** | FW에서 RA7 감시 + 래치 정지 + 카운트 로깅 |
| 모터 NTC(TEMP1) 미사용 | 코일 과열 → 절연 손상, 자석 접착제 열화 → **링자석 탈락** | AN4 읽기 + 온도 기반 전류 디레이팅 |
