# 01. 3상 BLDC(PMSM) 제어기 개발 프로세스 가이드

> 일반적인 개발 순서를 N25(코일 + 링자석 + iC-MU150 + PIC32MK + DRV8350RH) 기준으로 정리했다.
> 원칙: **"아래 단계가 검증되지 않으면 위 단계로 올라가지 않는다."** 문제가 생겼을 때 원인을 한 단계 안으로 좁힐 수 있다.

---

## 전체 흐름

```
[0] 요구사항 정의
   ↓
[1] 모터/센서 특성 파악 (R, L, Ke, 극쌍수, 관성, 마찰)        ← G1
   ↓
[2] 엔코더 검증 (방향, 분해능, 자석 상태, 각도 연속성)        ← G2
   ↓
[3] 전력·제어 HW 설계/검증 (전원, 게이트, 데드타임, 보호)      ← G3, G4
   ↓
[4] 전류 센싱 검증 (오프셋, 이득, 부호, ADC 타이밍)            ← G5
   ↓
[5] 전기각 정렬 (상순서, 극쌍수, 오프셋)                       ← G6
   ↓
[6] 전류(토크) 루프  Id/Iq PI                                  ← G7
   ↓
[7] 속도 루프 → [8] 위치 루프                                  ← G8
   ↓
[9] 보호 기능 (Fault 주입 시험)                                ← G9
   ↓
[10] 정격·내구·환경 검증 (+ 실제 AMR 주행 조건)                ← G10
```

---

## [0] 요구사항 정의

AMR 휠 구동기 기준으로 반드시 숫자로 정해야 하는 항목:

| 구분 | 항목 | N25에서 확인할 값 |
|------|------|-------------------|
| 전원 | 공칭/최대/최소 버스 전압 | 48V 배터리 (만충 54.6V 내외 추정), 회생 시 최대 전압 |
| 출력 | 연속/피크 토크, 연속/피크 전류 | 현재 FW 피크 Iq ≈ 28A, **연속 정격 미정의** |
| 출력 | 정격/최대 속도 | 주행 최고속도 → 휠 rpm → 모터 rpm (감속기 유무) |
| 제어 | 모드 | 현재: 속도명령을 적분한 위치 추종 (Diff mode) |
| 안전 | 과전류/과전압/저전압/과열/스톨/엔코더 이상 | 아래 [9] 참고 |
| 동작 | 로봇 질량 + **최대 적재 하중**, 최대 가감속, 경사로, 바닥 마찰계수 | 슬립 한계 토크 계산의 근거 |
| 회생 | 감속 에너지 처리 | 배터리가 흡수? BMS 차단 시? 제동저항 없음 |

> **연속전류 vs 피크전류**, **상전류 vs DC 입력전류**, **기계각 vs 전기각**을 처음부터 구분해 문서화한다.
> 특히 AMR에서는 "바퀴가 미끄러지지 않는 최대 토크" `T_slip = μ · N · r_wheel`이 모터 피크 토크보다 작은 경우가 많다. 이 값보다 큰 전류는 슬립만 유발한다.

## [1] 모터 특성 파악 (G1)

| 파라미터 | 측정 방법 | 왜 필요한가 |
|----------|-----------|-------------|
| 극쌍수 p | 손으로 1회전 시 역기전력 주기 수 | 전기각 = p × 기계각. N25 FW는 **p = 7** |
| 상저항 Rs | 상간 저항/2 (Y결선), 4선식 측정 | 전류 PI의 Ki, 발열 계산 |
| 인덕턴스 Ls (Ld, Lq) | LCR 미터 상간/2, 회전자 위치별 측정 | 전류 PI의 Kp, 전류 리플 |
| 역기전력 상수 Ke | 일정 속도로 돌리며 상간 전압 측정 | 최고속도 전압 여유, BEMF 피드포워드 |
| 토크 상수 Kt | Kt = 1.5 · p · ψm (진폭불변 dq 기준) | 전류 ↔ 토크 환산, 슬립 한계 전류 |
| 관성 J, 점성/쿨롱 마찰 | 가감속 시험, 정속 전류 | 속도 루프 튜닝, 마찰 보상 |
| 열 시정수 τ_th | 정전류 인가 후 코일 온도 상승 곡선 | **I²t 보호 설계의 핵심** |
| 자석 허용 온도 | 자석 등급(N, SH, UH…) | 감자(減磁)·접착제 열화 한계 |

> **N25 현황**: 펌웨어에 R, L, Ke, J 값이 정의되어 있지 않다 (`MOTOR_R`은 `FF_VOLTAGE` 미정의로 미사용). 전류 PI 게인(700/10)은 경험적으로 정한 값으로 보인다. → **1주차 실습: R, L, Ke 실측**

## [2] 엔코더 검증 (G2)

N25는 **iC-MU150** (자기식 오프축 Nonius 절대 엔코더) 사용:
- SPI로 절대각 읽기 (`MU150_ReadSensor()`) → 부팅 시 1회만 사용
- ABZ(인크리멘탈) 출력 → PIC32 QEI로 카운트 → 운전 중 위치/전기각 계산 (16384 cnt/rev)

체크리스트:
- [ ] 자기 트랙과 센서 사이 공극, 편심, 기울기 (MU150 데이터시트 허용값)
- [ ] MU150 상태 레지스터(0x77) 에러 비트: 자석 약함/강함, Nonius 에러 (`STAT.b.NON_CTR`)
- [ ] 1회전 = 16384 카운트 정확한지 (여러 바퀴 돌려 누적 오차 확인)
- [ ] **고전류 운전 중 QEI 카운트 유실 여부**: 절대각(SPI)과 QEI 누적값을 주기적으로 비교 → 차이 로그
- [ ] 회전 방향(MDR 설정)과 제어 좌표계 일치

---

## [3] 전력·제어 HW 검증 (G3, G4)

전원 투입 순서 (모터 연결은 맨 마지막):
1. 보조전원(5V/3.3V), MCU 클록, 리셋, 디버거
2. CAN, EEPROM, MU150 SPI 통신
3. 게이트드라이버 DRV8350RH: ENABLE, **nFAULT 핀 상태**, IDRIVE/VDS/MODE 저항 설정값 확인
4. 전류 제한 전원으로 낮은 전압(예: 12V)에서 무부하 게이트 파형
5. 하이/로우사이드 상보 PWM, **데드타임 실측**, 동시도통 없음 확인
6. 스위칭 노드(SHx) 링잉/언더슛 측정 (차동 프로브 필수)
7. 더미 부하(RL) → 마지막에 모터

---

## [4] 전류 센싱 검증 (G5)

N25는 **INA240A1 (Gain 20) + 2mΩ 션트, 상 직렬(in-line) 3채널**:
- 감도: 2mΩ × 20 = 40 mV/A → ADC 12bit/3.3V → **20.14 mA/LSB** (FW `CURRENT_CONSTANT`와 일치)
- 측정 범위: 중점 1.65V 기준 ±1.65V → **±41A**

체크:
- [ ] 오프셋(무전류) 평균 및 온도 드리프트 → FW `CurrentNulling()` 1000회 평균
- [ ] 알려진 DC 전류로 이득 보정
- [ ] 세 상 합 `Ia + Ib + Ic ≈ 0` (N25는 3상 다 측정하지만 FW는 2상만 사용 중 → 진단에 활용 가능)
- [ ] ADC 트리거 시점이 스위칭 에지와 겹치지 않는지 (in-line 센싱은 덜 민감하지만 확인 필요)

---

## [5] 전기각 정렬 (G6)

```
θe = wrap( p · θm + θoffset )
```
- N25 FW: `DQ_align()`이 A상에 고정 전압벡터를 계단식으로 인가 → 회전자 정렬 → 그 때의 MU150 절대값을 `InitPos_DQ_MU`로 EEPROM 저장
- 부팅 시 `EncoderReset_from_MU150()`에서 `MAG_AXIS = MU150 − InitPos_DQ_MU`로 전기각 원점 설정, 이후 QEI 증분으로만 갱신

검증:
- [ ] 여러 기계 위치에서 정렬 반복 → 오프셋 일관성
- [ ] 정방향/역방향 동일 Iq에서 토크 대칭
- [ ] 무부하 회전 시 Id ≈ 0, 무부하 전류 최소

---

## [6] 전류 루프 (G7)

- Clarke → Park → PI(Id, Iq) → 역Park → SVPWM
- 초기 게인 (연속시간):  `Kp = L · ωc`,  `Ki = R · ωc`  (ωc = 원하는 대역폭, 보통 PWM 주파수의 1/10~1/20 이하)
- 반드시 넣을 것: 전압 포화 처리, **올바른 스케일의 Anti-windup**, DC 버스 전압 보상, (고속 시) dq 디커플링/BEMF 피드포워드
- 시험: Iq Step (상승시간/오버슈트), 회전자 각도별 응답 동일성, 전압 포화 시 거동

---

## [7] 속도 루프 / [8] 위치 루프 (G8)

표준 캐스케이드:
```
θ* ─(P)→ ω* ─(PI)→ Iq* ─(PI)→ Vq*
          ↑ +ω_ff      ↑ +Iq_ff(가속도·마찰)
```
- 대역폭: **전류 > 속도(전류의 1/5~1/10) > 위치(속도의 1/3~1/5)**
- 속도 추정: 엔코더 차분 + 필터 (또는 PLL/관측기)
- 위치 루프 출력(ω*)과 속도 루프 출력(Iq*) 모두 **제한 + anti-windup**
- AMR 휠: 위치 오차를 무한정 누적하지 않도록 **추종오차 제한(following error clamp)** 필수

> **N25 현황**: 속도 루프 없이 위치 PD가 바로 Iq*를 만든다 → [03 문서](03_N25_FW_구조_분석.md) 참고

## [9] 보호 기능 (G9)

계층적으로 설계한다. 빠른 것은 HW, 느린 것은 FW.

| 계층 | 응답 시간 | 항목 | N25 현황 |
|------|-----------|------|----------|
| HW (게이트드라이버) | 수 µs | VDS OCP(단락), UVLO, 게이트 Fault | DRV8350 내부 기능. **설정값 확인 필요** |
| HW → MCU PWM Fault | < 1 µs | nFAULT → PWM 강제 OFF | **미연결/미사용** (nFAULT → RA7, FLT 핀 아님, FW 미판독) |
| FW 빠른 루프 (20kHz) | 50 µs~1 ms | 상전류 순시 과전류, Vbus 과전압/저전압 | **비활성 / Vbus 측정회로 없음** |
| FW 중간 (1kHz) | 10~100 ms | I²t, 스톨/JAM, 추종오차, 엔코더 상태 | JAM/CUR: 0.8초 지속 평균. **I²t 없음** |
| FW 느린 | 1 s | 보드/모터 온도 | **온도 핸들러 미호출, 모터 온도 미측정** |

Fault 주입 시험: 상 단락, 상 단선, 엔코더 커넥터 탈거, 바퀴 락, 전원 순간 차단, CAN 끊김, 회생 중 배터리 차단.

## [10] 정격·내구·환경 검증 (G10)

- 다이나모/토크센서: 토크-전류 선형성, 효율 맵, 연속 정격 온도 포화
- **AMR 실주행 시나리오** (이번 문제의 핵심):
  - 최대 적재 + 급가속/급감속 + 제자리 회전
  - 저마찰 바닥(에폭시, 물기), 문턱 넘기, 한쪽 바퀴 공회전
  - 벽/장애물에 밀린 상태로 주행 명령 유지 (스톨)
  - 각 시나리오에서 **Iq, Id, 위치오차, 상전류, Vbus, FET/코일 온도**를 동시 로깅
